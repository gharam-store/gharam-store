# متجر غرام 🧶

تطبيق ويب كامل لبيع منتجات الهاند ميد (كروشيه) لناس بتقدر الشغل اليدوي.

## الفكرة والمستخدم المستهدف

- **المشكلة:** صانعة الهاند ميد بتبيع من خلال رسائل واتساب/انستجرام المتفرقة، فبيتضيع الطلبات ومفيش كتالوج واضح بأسعار ومخزون.
- **المستخدم المستهدف:** البائعة (صاحبة الصفحة) والعميل اللي بيقدر الشغل اليدوي وعايز يشوف المنتجات ويطلب بسهولة من الموبايل.

## الخصائص الأساسية (اتنفذت واتختبرت)

- كتالوج منتجات مع تصنيفات وبحث فوري.
- عرض المخزون المتاح لكل منتج، وزر الأضافة يتعطل لما يخلص.
- سلة مشتريات محفوظة في المتصفح (localStorage) مع تعديل الكميات.
- طلب (Checkout) ببيانات العميل مع تحقق كامل على السيرفر: الاسم، رقم التليفون، المحافظة (قائمة بمحافظات مصر الـ 27 كلها)، العنوان، الكميات، وتوفر المخزون.
- الإجمالي بيتحسب على السيرفر (مش من المتصفح) عشان ميحصلش تلاعب.
- بعد الطلب: رقم طلب + زر يفتح واتساب برسالة الطلب جاهزة للبائعة.
- لوحة إدارة بسيطة: إضافة منتج وعرض الطلبات، محمية بكود بيتحط كمتغير بيئة `ADMIN_KEY` على السيرفر.

## التقنية وليه

- **Node.js + Express:** سيرفر خفيف وسريع، مناسب لمتجر صغير، وسهل الاستضافة على أي خدمة (Render, Railway, VPS).
- **ملف JSON للتخزين (`data/store.json`):** بدون قاعدة بيانات خارجية عشان التشغيل يبقى بأمر واحد. مناسب لحجم متجر صغير، والترقية لـ SQLite/Postgres سهلة لأن طبقة البيانات معزولة في `src/db.js`.
- **واجهة HTML/CSS/JS خالصة (بدون إطار عمل):** تحميل سريع على الموبايل، ودعم RTL عربي كامل.

## التشغيل

```bash
npm install
npm start          # http://localhost:3000
```

## الاختبار

```bash
npm test           # 10 اختبارات: منتجات، بحث، طلبات، مخزون، صلاحيات الإدارة
```

## إعدادات (متغيرات بيئة)

| متغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ السيرفر |
| `ADMIN_KEY` | _(عشوائي)_ | كود لوحة الإدارة — لازم يتظبط على السيرفر؛ من غيره الإدارة مقفولة |
| `SELLER_WHATSAPP` | `201550894660` | رقم واتساب البائعة لاستقبال الطلبات |
| `DATA_FILE` | `data/store.json` | ملف البيانات |

## اللي لسه ناقص قبل النشر الفعلي

- **استضافة:** رفع على Render/Railway/VPS + دومين.
- **صور حقيقية** للمنتجات بدل الإيموجي (رفع صور من لوحة الإدارة).
- **دفع إلكتروني:** فودافون كاش / انستاباي / Paymob — حاليا التأكيد بيتم على واتساب.
- **حماية إنتاجية للإدارة:** الكود الحالي كود واحد بسيط؛ الأفضل تسجيل دخول كامل.
- **حالات الطلب:** تحديث الحالة (قيد التجهيز/اتشحنت) وإشعار للعميل.
